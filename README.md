One satirical sentence roasting a lawmaker who writes the rules for artificial intelligence, cryptocurrency, and the internet — but cannot convert his own bill to PDF. The chairman spent two years writing the rules for the whole digital world, then emailed his bill to himself after midnight and screenshotted all 214 pages one by one, because the Export to PDF button, he insists, is a rumor started by Big Tech.

The entry is a single sentence of 310 characters. It builds the lawmaker's authority first (two years writing the rules for AI, crypto, and the internet) and undercuts it with the file he cannot convert; the punch lands on the last few words, and the failure is concrete — 214 pages, screenshotted one by one — not a worn tech-illiteracy cliche.

## Run it

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt`. The program validates the entry before writing (1–320 characters, not only white space, exactly one sentence, names PDF) and reads the file back afterwards to prove what landed on disk is byte for byte the validated entry.
